# 快捷指令

快捷指令由程序生成，不用手动搭。它只做三件事：登录、截屏上传，然后把服务端返回的每一步显示出来。菜单、提示和分支都在服务端（[internal/server/flow.go](../internal/server/flow.go)），以后改流程不用重装快捷指令。

## 下载

签名好的快捷指令放在 [GitHub Release](https://github.com/cr-zhichen/ledger-snap/releases/latest) 里，在 iPhone 上用 Safari 打开 [这个链接](https://github.com/cr-zhichen/ledger-snap/releases/latest/download/ledger-snap.shortcut) 即可下载。GitHub 的附件名不能用中文，所以附件叫 `ledger-snap.shortcut`，添加后的快捷指令也叫“ledger-snap”，可以在快捷指令 App 里改名为“截图记账”。

## 自己生成

需要在 macOS 上运行，签名用系统自带的 `shortcuts sign`：

```bash
mise run shortcut -- --server https://snap.example.com
```

生成的文件是 `dist/截图记账.shortcut`，已经签名，iPhone 可以直接导入。

- 导入后快捷指令的名称就是文件名，可以用 `--out` 改。
- `--server` 和 `--invite` 是第一次登录时服务器地址和邀请码的默认答案，可以不填。
- 签名时 Apple 每次现签一张一次性证书，证书名是随机字符串，不含签名者的账户信息，所以签名文件可以公开发布。`dist/` 是构建产物，不提交到 Git。
- 发布新版本时，用 `mise run release:shortcut <标签>` 生成、签名并上传到这个版本的 Release。

## 安装

1. 在 iPhone 上用 Safari 下载 Release 里的快捷指令后点开；自己生成的文件可以隔空投送到 iPhone，或者放进 iCloud 云盘，再在「文件」App 里打开。
2. 点「添加快捷指令」。安装时不用填写任何内容：带安装问题的快捷指令点添加后设置页不会关闭，所以服务器地址和邀请码改到第一次运行时填写。
3. 分享给朋友：把上面的下载链接、服务器地址和邀请码发给他们，第一次运行时填写。

## 第一次运行

- 装好后可以先在快捷指令 App 里点一次运行，完成登录。这次截到的是快捷指令自己的界面，会提示不记账，不影响登录。
- 快捷指令依次询问服务器地址、邀请码、钱迹账号和密码，只把密码的 MD5 发给服务器。
- 登录成功后，服务器地址、邀请码和令牌分别存在 iCloud 云盘「Shortcuts」文件夹下 `ledger-snap` 文件夹里的 `server.txt`、`invite.txt` 和 `token.txt`，文件夹不存在时自动创建。登录失败时什么都不存，下次运行重新询问。
- 以前的版本把令牌存在「Shortcuts」文件夹里的 `ledger-snap-token.txt`，新版本登录后会删掉它。从旧版本升级后要重新登录一次。
- 第一次上传截图时，系统会询问是否允许把图片发送给你的服务器，选「始终允许」。
- 令牌失效或钱迹密码改了时，快捷指令会删掉 `token.txt` 并提示，再运行一次即可重新登录。服务器地址和邀请码预填上次的，确认即可。
- 要换服务器地址，在「文件」App 里删掉 `ledger-snap/token.txt`，再运行时会重新登录，可以改服务器地址。

## 触发

打开「设置 › 辅助功能 › 触控 › 轻点背面 › 轻点两下」，选择这个快捷指令。iPhone 15 Pro 及以上也可以在「设置 › 操作按钮」里绑定。

停在支付详情或账单列表页时触发：「截屏」截的是当时的屏幕。在快捷指令 App 里点运行，截到的是快捷指令自己的界面。

## 使用

单笔识别直接显示该笔结果；多笔识别先显示账单列表，选择一笔后可确认、修改或删除，再返回列表处理其他笔。识别结果和修改菜单的第一行都写着这笔是“已记账”还是“还没记账”，按钮也不一样：

- **已记账**：已经写进钱迹，按钮是「完成 / 修改 / 从钱迹删除」。点完成只是结束，不点、直接关掉也一样记上了；点从钱迹删除会删掉这笔。
- **还没记账**：有拿不准的字段、疑似重复，或者转账缺账户时，第一行接着说明原因，拿不准的字段后面带问号。按钮是「确认记账 / 修改 / 不记了」，点确认记账才写入；点不记了，或者中途关掉快捷指令，这笔都不会记。
- **修改**：可以选账户、收支类型、分类，改金额、优惠、手续费、时间，或者用一句话改；改完回到识别结果。
  - 优惠和手续费填 0 表示去掉。转账和还款的金额是转出账户实际扣掉的钱：有手续费时含手续费，有优惠时是优惠后的金额，结果里会写出到账多少。
  - 已记账的单子，每改一项就直接同步到钱迹，结果上方显示“已改好，钱迹里同步改了”，不用再确认。
  - 还没记账的单子改完仍然没记账，结果上方显示“已改好”，还要点确认记账。
  - 改成转账或还款时，会接着选转出和转入账户。
  - 在钱迹里新建了账户或分类后，识别时没认出账户或分类会自动刷新目录，目录变化时重新匹配；修改时找不到新账户或新分类，可以用「刷新账户和分类」手动拉取。
  - 改失败时，结果上方显示“没改成”和原因，原来的账单保持不变。已记账的单子改成记不了的样子，比如转账账户不全、没有汇率，也会这样拒绝，钱迹里的账单不受影响。
  - 输入框点关闭会直接结束快捷指令，还没记账的这笔也就放弃了。想回到修改菜单，留空点完成即可，金额填 0 也行；时间框里预填了原来的时间，要先清空。
- **外币**：金额后面会带币种，例如“支出 12.99 USD = 93.50 CNY”“转账 3940.45 HKD → 500.00 USD”。
  - 截图里只有一种币种时，另一边按钱迹的汇率估算，显示为“约”，先不记账；点确认记账，或在修改里用「入账金额」（转账为「转入金额」）改成银行实际扣款或到账的金额。
  - 换汇时转出、转入账户各用各的币种，钱迹里两个账户分别按卖出和买入金额变动。
- **优惠和手续费**：支出显示为“支出 41.20（优惠 5.00）”，只是记下省了多少。还款优惠、提现手续费会写进钱迹，两边账户按实际金额变动，例如“信用卡还款 995.00（优惠 5.00，到账 1000.00）”“转账 2002.00（手续费 2.00，到账 2000.00）”。电商订单上有几项优惠又没有合计时，会多花两三秒把它们加起来。
- **待支付页面**：还没付款的页面，比如 Apple Pay 的确认弹窗，也照常记账。最后没付款时点从钱迹删除。付款后又截了成功页时，金额和账户相同、前后不超过 5 分钟的会提示可能重复。
- **不是支付页面**：直接通知不记账的原因，支付失败和已取消的也不记。

## 工作原理

快捷指令先等待 1 秒，让快捷指令运行时的动画消失，再截屏并转成 JPEG，作为请求体发给 `POST /v1/flow/recognize`。之后循环执行：按返回的 `action` 显示对话框，把回答以 `{"value": "回答"}` 发到 `next` 指向的地址，用新的返回值进入下一轮。

返回的字段：

| 字段 | 说明 |
| --- | --- |
| `action` | `choose` 从 `options` 中选一项；`text`、`number` 输入文字或数字；`done` 显示 `message` 通知后结束；`relogin` 删除令牌文件，提示 `message` 后结束 |
| `prompt` | 对话框的标题 |
| `options` | 选项 |
| `default` | 输入框里预填的内容 |
| `next` | 下一步的路径，例如 `/v1/flow/r_xxx/main` |
| `message` | 结束时显示的文字 |

这几个接口总是返回 HTTP 200，因为快捷指令不能按状态码分支，出错时也用 `done` 或 `relogin` 表示。

| 接口 | 说明 |
| --- | --- |
| `POST /v1/flow/login` | JSON `account`、`password_md5`、`invite_code`，返回 `token`；失败时只有 `message` |
| `POST /v1/flow/recognize` | 请求体是截图本身，也接受 multipart 的 `image` 字段 |
| `POST /v1/flow/{记录}/{步骤}` | JSON `value`，返回下一步 |

## 测试情况

在 macOS 27 虚拟机里用快捷指令 App 验证过以下流程，iPhone 真机还没有测，包括从 Safari 下载后导入这一步：

- 导入；
- 登录失败时的提示；
- 截屏上传，以及上传前的权限询问；
- 识别结果菜单、修改金额和时间、删除后的通知。

第一次运行时询问服务器地址和邀请码、把数据存进 `ledger-snap` 文件夹，是改掉安装问题后的新流程，还没有在真机上测过。

以前的版本用安装问题填服务器地址和邀请码。在 macOS 27 和 iOS 27 上，带安装问题的快捷指令点「添加快捷指令」后，设置页会关掉又立刻重新弹出，看起来卡住了，关掉设置页后才真正添加。只有一个文本动作和一个问题的快捷指令也一样，所以不再使用安装问题。

没登录 iCloud 的 Mac 上没有快捷指令文件夹，读取文件会报“所选位置不存在”。iPhone 关闭 iCloud 云盘的情况还没有测试。
