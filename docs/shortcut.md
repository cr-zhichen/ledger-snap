# 快捷指令

快捷指令由程序生成，不用手动搭。它只做三件事：登录、截屏上传，然后把服务端返回的每一步显示出来。菜单、提示和分支都在服务端（[internal/server/flow.go](../internal/server/flow.go)），以后改流程不用重装快捷指令。

## 下载

签名好的快捷指令放在 [GitHub Release](https://github.com/cr-zhichen/ledger-snap/releases/latest) 里，在 iPhone 上用 Safari 打开 [这个链接](https://github.com/cr-zhichen/ledger-snap/releases/latest/download/ledger-snap.shortcut) 即可下载。GitHub 的附件名不能用中文，所以附件叫 `ledger-snap.shortcut`，添加后的快捷指令也叫“ledger-snap”，可以在快捷指令 App 里改名为“截图记账”。

## 自己生成

需要在 macOS 上运行，签名用系统自带的 `shortcuts sign`：

```bash
mise run shortcut -- --server https://snap.example.com
```

生成的文件是 `dist/截图记账.shortcut`，已经签名，iPhone 可以直接导入。

- 导入后快捷指令的名称就是文件名，可以用 `--out` 改。
- `--server` 和 `--invite` 是安装时两个问题的默认答案，可以不填。
- 签名时 Apple 每次现签一张一次性证书，证书名是随机字符串，不含签名者的账户信息，所以签名文件可以公开发布。`dist/` 是构建产物，不提交到 Git。
- 发布新版本时，用 `mise run release:shortcut <标签>` 生成、签名并上传到这个版本的 Release。

## 安装

1. 在 iPhone 上用 Safari 下载 Release 里的快捷指令后点开；自己生成的文件可以隔空投送到 iPhone，或者放进 iCloud 云盘，再在「文件」App 里打开。
2. 点「添加快捷指令」，填写服务器地址和邀请码。
3. 分享给朋友：把上面的下载链接和邀请码发给他们，安装时同样要填这两项。不要用快捷指令 App 的「拷贝 iCloud 链接」分享自己装好的那份，里面可能带着你填过的服务器地址和邀请码。

## 第一次运行

- 快捷指令会要求输入钱迹账号和密码，只把密码的 MD5 发给服务器。
- 登录后，令牌存在快捷指令文件夹里的 `ledger-snap-token.txt`，也就是 iCloud 云盘的「Shortcuts」文件夹。
- 第一次上传截图时，系统会询问是否允许把图片发送给你的服务器，选「始终允许」。
- 令牌失效或钱迹密码改了时，快捷指令会删掉令牌文件并提示，再运行一次即可重新登录。

## 触发

打开「设置 › 辅助功能 › 触控 › 轻点背面 › 轻点两下」，选择这个快捷指令。iPhone 15 Pro 及以上也可以在「设置 › 操作按钮」里绑定。

必须停在支付结果页时触发：「截屏」截的是当时的屏幕。在快捷指令 App 里点运行，截到的是快捷指令自己的界面。

## 使用

识别完弹出识别结果和「确认 / 修改 / 删除」：

- **已经记账**：标题以“已记账”开头。点确认结束，点删除会从钱迹删掉这笔。
- **还没记账**：有拿不准的字段、疑似重复，或者转账缺账户时，先说明原因，拿不准的字段后面带问号。点确认才写入，点删除就放弃。
- **修改**：可以选账户、收支类型、分类，改金额、时间，或者用一句话改；改完回到识别结果。
  - 改成转账或还款时，会接着选转出和转入账户。
  - 在钱迹里新建了账户或分类后，识别时没认出账户或分类会自动重新拉取一次，再识别一遍；修改时找不到新账户或新分类，可以用「刷新账户和分类」手动拉取。
  - 改失败时，结果上方会说明原因，原来的账单保持不变。
- **外币**：金额后面会带币种，例如“支出 12.99 USD = 93.50 CNY”“转账 3940.45 HKD → 500.00 USD”。
  - 截图里只有一种币种时，另一边按钱迹的汇率估算，显示为“约”，先不记账；确认，或在修改里用「入账金额」（转账为「转入金额」）改成银行实际扣款或到账的金额。
  - 换汇时转出、转入账户各用各的币种，钱迹里两个账户分别按卖出和买入金额变动。
- **待支付页面**：还没付款的页面，比如 Apple Pay 的确认弹窗，也照常记账。最后没付款时点删除。付款后又截了成功页时，金额和账户相同、前后不超过 5 分钟的会提示可能重复。
- **不是支付页面**：直接通知不记账的原因，支付失败和已取消的也不记。

## 工作原理

快捷指令先等待 1 秒，让快捷指令运行时的动画消失，再截屏并转成 JPEG，作为请求体发给 `POST /v1/flow/recognize`。之后循环执行：按返回的 `action` 显示对话框，把回答以 `{"value": "回答"}` 发到 `next` 指向的地址，用新的返回值进入下一轮。

返回的字段：

| 字段 | 说明 |
| --- | --- |
| `action` | `choose` 从 `options` 中选一项；`text`、`number` 输入文字或数字；`done` 显示 `message` 通知后结束；`relogin` 删除令牌文件，提示 `message` 后结束 |
| `prompt` | 对话框的标题 |
| `options` | 选项 |
| `default` | 输入框里预填的内容 |
| `next` | 下一步的路径，例如 `/v1/flow/r_xxx/main` |
| `message` | 结束时显示的文字 |

这几个接口总是返回 HTTP 200，因为快捷指令不能按状态码分支，出错时也用 `done` 或 `relogin` 表示。

| 接口 | 说明 |
| --- | --- |
| `POST /v1/flow/login` | JSON `account`、`password_md5`、`invite_code`，返回 `token`；失败时只有 `message` |
| `POST /v1/flow/recognize` | 请求体是截图本身，也接受 multipart 的 `image` 字段 |
| `POST /v1/flow/{记录}/{步骤}` | JSON `value`，返回下一步 |

## 测试情况

在 macOS 27 虚拟机里用快捷指令 App 验证过以下流程，iPhone 真机还没有测，包括从 Safari 下载后导入这一步：

- 导入，以及安装时的两个问题；
- 登录失败时的提示；
- 截屏上传，以及上传前的权限询问；
- 识别结果菜单、修改金额和时间、删除后的通知。

Mac 上有两个现象：

- 导入时点「添加快捷指令」后，设置表单可能不会自动关闭，但快捷指令已经添加好了，点取消关掉即可。
- 没登录 iCloud 的 Mac 上没有快捷指令文件夹，读取令牌会报“所选位置不存在”。iPhone 关闭 iCloud 云盘的情况还没有测试。
